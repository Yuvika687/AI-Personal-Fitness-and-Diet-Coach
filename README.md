## 🚀 What is this?

Tired of generic fitness plans that don't work for YOU?

**AI Personal Fitness & Diet Coach** is an intelligent fitness platform 
that acts as your 24/7 personal trainer + nutritionist + habit coach — 
powered by AI.

No more guesswork. No more one-size-fits-all plans.
Just smart, personalized fitness — built for YOU. 🎯

## ✨ Features

- 🤖 **AI Coach** — Real-time guidance & chat assistant
- 🥗 **Diet Planner** — Personalized nutrition plans
- 💪 **Workout Logger** — Track every rep, every set
- 📊 **Habit Tracker** — Build consistency, crush goals
- 🧍 **Pose Analysis** — AI-based form correction

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Python, FastAPI |
| Database | PostgreSQL, SQLite |
| Frontend | HTML, CSS, JavaScript |
| AI/ML | Scikit-learn, NLP |

## 🎯 Why I Built This

Manual fitness planning is broken —
- ❌ No personalization
- ❌ No automation
- ❌ No real-time feedback

This project fixes all of that with AI. 🙌

## 📦 Installation
```bash
git clone https://github.com/Yuvika687/AI-Personal-Fitness-and-Diet-Coach.git
cd AI-Personal-Fitness-and-Diet-Coach
pip install -r requirements.txt
uvicorn main:app --reload
```
