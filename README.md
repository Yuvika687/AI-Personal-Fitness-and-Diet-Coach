## 🚀 What is this?

Tired of generic fitness plans that don't work for YOU?

## 📦 Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Yuvika687/AI-Personal-Fitness-and-Diet-Coach.git
cd AI-Personal-Fitness-and-Diet-Coach
```

### 2. Backend Setup
```bash
cd backend
pip install -r requirements.txt
python create_tables.py
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 3. Frontend Setup
```bash
cd frontend
python -m http.server 3000
```

### 4. Access the App
- 🌐 Frontend: http://localhost:3000
- ⚙️ Backend API: http://localhost:8000
- 📄 API Docs: http://localhost:8000/docs
