# 🏋️ AI Gym & Fitness Assistant
## Major Project - Unlox | Trivion Technology
### Student: Yogender | Deadline: 15 December 2025

## 🎯 Project Overview
An AI-powered fitness ecosystem that integrates workout detection, diet planning, behavioral tracking, and conversational AI to revolutionize personal fitness management.

## ✅ Features Implemented
1. **AI Gym Trainer** - Real-time pose detection with MediaPipe
2. **AI Dietician** - Personalized meal plans with BMI calculator  
3. **Smart Gym Assistant** - Habit tracking with AI predictions
4. **Virtual Gym Buddy** - Gemini-powered AI chatbot
5. **Performance Analyzer** - Progress tracking & scoring
6. **Gym Recommender** - Location-based gym suggestions
7. **Behavioral AI** - Skip prediction & motivation system

## 🛠️ Technical Stack
- **Frontend**: HTML5, CSS3, JavaScript (Luxury Black/White Theme)
- **Backend**: Python FastAPI
- **AI/ML**: Google Gemini 2.5 Flash-Lite, MediaPipe Pose Detection
- **Database**: SQLite with SQLAlchemy ORM
- **Authentication**: JWT Token-based security
- **APIs**: RESTful architecture with CORS support
